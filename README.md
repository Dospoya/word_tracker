## Contribution Guidelines

### Conventional Commits

This repo follows the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) specification.
Each commit message must include a type, and a description.
Description should answer the question: "What change will this commit introduce?".

**For example:**

- Good:

```text
feat: add word frequency analysis to track usage patterns
fix: resolve memory leak when processing large text files
docs: update installation instructions for macOS users
```

- Bad:

```text
feat: new feature
fix: bug fix
update stuff
```
